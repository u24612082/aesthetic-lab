KNOW WHAT'S CONNECTED

Checking your coach

CHECKING

Checking Claude configuration and available records.

Your Mac reviews saved workout, routine and food changes automatically using your installed Claude Code client and subscription sign-in. Reviews appear here without opening Terminal or entering prompts.

Uses your Claude subscription limits. The dashboard does not make paid API calls in this mode. Changes are batched for 20 seconds, with at most one automatic review per 15 minutes and 12 per 24 hours.

Connect Claude

Use an Anthropic API key ↗. The key is saved privately on this Mac and is never displayed again. Connecting enables automatic AI audits, which send aggregate training and food data to Anthropic when records are available. API usage is billed by Anthropic.

The connection check verifies model access without sending health records or generating an audit. Local rules remain available without a key.

EARN THE NEXT INCREASE

Technique-gated progression

DETERMINISTIC RULE

Amplitude + force control: ≥3/5 for isolation, ≥4/5 for compounds. Every working set must pass. Missing measured scores keep the gate closed.

Passing technique permits a progression review; it does not approve a weight increase. Source: ANPC86 / claude-smart-gym-coach ↗. No technique scores are inferred from HealthKit summaries.
